## About

This repository accompanies my ongoing research project on the Cosmic
Gamma-Ray Background (CGB) conducted remotely with Prof. Inoue's group
at Shibaura Institute of Technology. The project focuses on constraining
the contributions of astrophysical source populations to the diffuse
gamma-ray flux, including:

- **Active Galactic Nuclei (AGN)** and their role in the unresolved CGB
- **Star-forming galaxies** as extended gamma-ray emitters
- **Exotic processes** — potential contributions from non-standard sources
- Deriving **lower bounds on source population parameters** using
  observational data from gamma-ray telescopes

**Primary tools:** Python (astropy, gammapy, NumPy, SciPy, Pandas), Matplotlib
